# 系统状态

在 DeepSeek Harness 里看这台机器的硬件状况：对话页输入框下方一条常驻的实时状态条，左侧栏一个图标进入历史曲线页。

## 功能

- **实时条**（对话页，输入框下方）：紧凑一行显示 CPU 利用率、内存已用/总量、GPU 利用率、显存已用/总量、GPU 温度，右侧「历史 ›」进入曲线页；数据断流时显示「重连中 / 数据已过期」。没有可用 GPU 时只显示一行「GPU 不可用」。
- **历史页**（左侧栏「系统状态」图标）：CPU、GPU、内存、显存的使用率各自一张曲线图（纵轴按数据自动缩放，并在标题旁显示最新值），外加 GPU 温度曲线与各固定磁盘的已用空间；可切换近 1 小时、6 小时、24 小时、7 天，横轴是所选时间窗口（不是数据实际跨度），在图上移动可读出该时刻的具体数值。
- **降级**：没有 NVIDIA 显卡或 `nvidia-smi` 不在 PATH 上时，GPU 相关项显示「不可用」，其余指标照常；历史目录不可写时只保留实时数据。

## 使用

安装并启用后即时生效，无需重启 DSH。首次安装后刷新一次页面即可看到实时条与左侧栏图标。

## 限制

- **采样频率**：每 3 秒一次；实时条随之每 3 秒刷新。
- **历史只在 DSH 运行时采样**：关掉 DSH、休眠、关机的时间段没有数据，曲线会在断档处断开。历史默认按天分文件保存在 `%DSH_HOME%/system-status/`，保留 7 天。
- **只有 GPU 温度**：Windows 的 ACPI 热区接口取不到可信的 CPU / 主板温度，需要 LibHardwareMonitor 这类带内核驱动的工具，本插件未接入。
- **数据面**：采样只在本机进行，HTTP 路由只返回数值（不包含机器名、用户名、路径），并且只监听 DSH 自己的回环地址。
